LaunchScout: a CrewAI research crew for founders

Enter a business idea, a city and a target customer. Four CrewAI agents research real competitors, read what customers say about them, find the market gap and write a sourced report with a recommended positioning and a 30-day launch plan.

01 · Challenge

The problem worth solving

Before launching, founders spend weeks hunting down competitors, prices and customer complaints across delivery apps, Google Maps listings, Instagram pages and websites.

LLMs can speed that up, but they also invent plausible-looking competitors and prices. A research report is only worth acting on if every price and claim links back to the page it came from.

02 · Approach

How I built it

  • Four agents with distinct roles. Market Researcher, Review Analyst, Strategy Analyst and Report Writer each have their own role, goal, backstory and tools.
  • Sequential tasks with context. Tasks run with Process.sequential, and each task receives the earlier tasks' output as context. A hierarchical mode with a manager LLM is available as an option.
  • Real tools. Google search and Google Maps reviews through Serper (lowest-rated first), a website scraper and a file writer. Without a Serper key the crew falls back to DuckDuckGo.
  • A price guardrail. The competitor table is sent back to the agent when a price does not appear in any page read during the run, or when fewer than three competitors have both a found price and a source.
  • Contracts and checks. Every task has a format-specific expected_output, and the app runs an automatic quality checklist: six sections, at least three competitors, and a price and source on every row.

04 · Agent roles

What each agent does

Market Researcher

Finds 3–5 real, operating competitors with prices, offers, channels and source URLs.

Review Analyst

Learns what customers praise and complain about for each competitor, quoting real reviews with sources.

Strategy Analyst

Builds the comparison matrix, picks the clearest market gap and recommends price and positioning.

Report Writer

Writes the six-section, founder-friendly report, including the 30-day launch plan, and saves it.

Live progress

Status cards and a step log show which agent is working and what it found.

Any idea, any city

Everything is driven by the form inputs, so no code changes are needed for a new market.

Guardrails & safety

Built to be safe in production

Live, tested protections in the deployed app, not just a demo.

SSRF-safe scraping

The scraper only reaches public http(s) hosts. Private, loopback and cloud-metadata addresses are blocked, and every redirect is re-checked.

Untrusted web content

Search results, pages and reviews are marked as data. Agents ignore instructions inside them, and each page is truncated.

Input checks

Length limits on every field. Harmful, illegal or off-topic ideas are refused without using up a run.

Cost & abuse caps

Caps on pages, searches, agent iterations, tokens and run time, plus 2 runs per hour per visitor and a daily cap.

Sourced, safe output

Reports must cite sources, HTML is escaped, and secrets and stack traces never reach the user.

06 · Result

What it delivers

One run produces a six-section report: key competitors, what customers complain about, the market gap, recommended positioning, a 30-day launch plan and sources, downloadable as Markdown or PDF.

Sample runs include healthy millet meal boxes in Coimbatore and at-home pet grooming in Bengaluru, with no code changes between them. The public app allows a few runs per day to keep API spend predictable.
